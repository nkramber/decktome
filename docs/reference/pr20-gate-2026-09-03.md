## The rest of the slice, under test

- The filters by role, color, mana value, type, and owned, and the sorts by mana value, name, and price: `deck-stats.test.ts` and `deck-view.test.tsx` "filters the cards and sorts them".
- The five stats with a text table each: the curve and the sources as before, and the type counts, the average mana value, and the cards to buy in `deck-view.test.tsx`.
- The London mulligan to six and to five with the reader's bottom choice, and the draw: `sample-hand.test.ts` and `deck-view.test.tsx` "draws a sample hand from the exact main deck".
- The printings with prices, newest set first, a digital one marked: `cardsvc.TestGetPrintingsOrdersNewestSetFirst` and `card-detail.test.tsx`.
- The rulings bulk file as the fourth snapshot file, optional on load: `cards.TestLoadRulingsKeysByOracleID`, `cards.TestPrintingsOfListsEveryPlayablePrinting`, and the refresh tests with four downloads. `TestLoadRulingsRealFile` read the real file of 2026-09-03 when `RULINGS_FILE` named it: 5.4 MB, 78,949 rulings of 19,938 cards, in a tenth of a second.

## The tree

Go build, vet, the `-race` suite, golangci-lint, `make ste-check`, the web lint, the web typecheck, and 256 web tests pass. `make proto` regenerated the Go and the TypeScript code for `GetRulings`, `GetPrintings`, and `Ruling`.

## What the gate does not prove

- A stored snapshot gains the rulings file on the worker's next refresh. Until then the panel says "The card data holds no rulings file yet", and the index logs the missing file once per load.
- The look of the sheet and the charts on a real screen. The owner reads them on the local stack.

Verdict: PASS. Time: the two suites, about three minutes. No provider call.
