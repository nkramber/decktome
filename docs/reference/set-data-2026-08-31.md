## The bonus sheet rule (2026-09-04, D-518)

Scryfall types a bonus sheet "masterpiece", and some sheets carry no parent set. Marvel Universe (`mar`, 2025-09-26) is one: 94 reprints of existing cards with Marvel art.

The resolver never lets a masterpiece set lead a family when a phrase matches several sets. An exact code or an exact name still resolves it. "Marvel" resolves to Marvel Super Heroes (`msh`) and its family alone. "Marvel's Spider-Man" (`spm`) stays out, because the resolver matches whole words and "marvel's" is another word. Checked against the Scryfall set list on 2026-09-04.

## The group rule (2026-09-04, D-525)

A reader who names a franchise as a group, "sets with Marvel characters", means every family of that franchise. The classify role writes the franchise word into `set_groups` and not into `set_names`, at prompt version 18. The set table's `ResolveGroup` drops the possessive from every word, so "marvel's" and "marvel" are one word. It matches whole words over every paper set. The answer is the union of the families of every matched base set, sorted, and a bonus sheet never joins.

"Marvel" as a group reaches `msc`, `msh`, `pspm`, `spe`, and `spm` in the snapshot of 2026-09-03. "Marvel" as a set name still means Marvel Super Heroes alone (D-518).
