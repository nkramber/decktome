## The cause

The lands, curve, and colors copies lose to their precon in every pair. So the bar over every axis reads the synergy axis alone. With 255 synergy pairs, 0.95 needs 238 wins, a synergy share of 0.93. The synergy axis read 0.84 in run 18, 0.85 in run 24, and 0.80 on 2026-09-26.

The synergy feature reads the card pairs of the real lists. The list corpus grew after 2026-09-15. More synergy copies then passed the check of D-653, 228 to 255, and the model lost 50 of them against 35. No code change, precon table, or card snapshot moved the share. The local store also fails now.

The daily refit checked no bar before #230, and each gate run read the local store. So no fit of the deployed data read the bar before 2026-09-26. UNVERIFIED: the model `20260925T061627Z` reads about 0.94 too, because it fitted on nearly the same lists.
