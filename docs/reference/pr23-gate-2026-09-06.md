4. The reader asks: "Build a lifegain Commander deck led by Karlov of the Ghost Council at bracket 3, with no spending limit."

## 4. Read

Three things a reader should know. First, the flow proves the path and not the model: the fake answers the same deck to every request, so a change in a prompt shows up nowhere here. Second, the budget row was the one surprise. It fires on an any-card pool, a decline works only on a question that is out, and the word rule of D-168 is what closes the slot without a number. Third, the run spends nothing by construction: the keys leave the environment, and every role names the fake, so a key in `.env` can not turn a smoke run into a paid one.

## 5. How to run it

Local: run `pnpm --dir web/apps/web exec playwright install chromium` once, stop `make dev`, then run `make smoke`. GitHub: open the workflow `smoke` and press "Run workflow". One run takes about 5 minutes of Actions time, most of it the installs, and the owner triggers it before a merge that touches the user path (D-313).
