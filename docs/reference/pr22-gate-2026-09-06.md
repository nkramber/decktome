## 4. Read

Three things a reader should know. First, the cap reads the ledger and not the sessions, so a user who deletes chats keeps the month's spend. Second, a ledger that can not be read refuses the turn, because a cap nobody can read is no cap. Third, the list is off in local mode, so `ALLOWLIST=1` is the way to see the refusal on the emulator: start `make dev`, add an email with `PROJECT_ID=mtg-local FIRESTORE_EMULATOR_HOST=127.0.0.1:8281 make allow EMAIL=...`, and sign in with another.
