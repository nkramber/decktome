# Quality audit of 2026-08-29

This document records the full quality audit of 2026-08-29, the owner's answers, and the fixes. Branch `quality-audit-fixes` holds every fix. The owner answered five questions, and D-302 to D-306 record them.

## 1. Scope and method

Six read-only auditors read the repo in parallel, one per area:

- The Go service layer: `agentsvc`, `sessions`, `decks`, `decksvc`, `revise`, `collectionsvc`, `collections`, `cardsvc`, `auth`, `cmd/api`, `cmd/worker`.
- The Go domain logic: `generate`, `candidates`, `questions`, `rules`, `cards`, `precons`, `scryfall`.
- The Go infrastructure and tools: `llm`, `gatekit`, the gate commands, `scripts/`, the Makefile.
- The web app under `web/`.
- The protos, CI, Docker, compose, the Firestore rules, and the security posture.
- The docs: contradictions with the repo, expired facts, STE gaps, stale instructions, and the hand-off.

Each auditor verified each finding against the code path before it reported. The audit found about 170 findings. Nine fix agents then worked one package group each, and each added a test per behavior change. The tree was green before the audit and is green after it.
