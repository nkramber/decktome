File: `docs/tools/codex_review.py:205-207`.

Trigger: a pull request has more than 100 review threads, and an unresolved thread appears after the first 100.

Expected: the target must read every review thread before it accepts the Gitar pass (D-832 and the `gitar-review` skill).
