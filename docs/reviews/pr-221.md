### P2-1: The session sync can erase concurrent usage

Status: open.

Open at: `04d6373905d017b7e08bfbf8d045cb46c2373a39`.

File: `go/internal/agentsvc/import.go:251`.

Trigger: A revise turn writes newer usage after `ReadImportBracket` reads the session, then `storeImportPower` reloads that session after a version conflict.

Expected: Preserve the current session usage and add the import judge usage, as required by D-447.
