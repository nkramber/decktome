## Findings

### P2-1: The live-test instructions understate share-link creation

Status: open.

Open at: `b86717d7e73006f59adf1bcc36d610090d592da8`.

File: `.claude/skills/live-test/SKILL.md:70`.

Trigger: Run the free sweep with `LIVE_SWEEP_BUILD=0` when the newest deck has no stored token.

Expected: The instructions state that the sweep reads a stored link or creates one, and that the link stays live until the deck ends (D-1069).

Actual: The instructions say the sweep reuses a stored link. The sweep clicks “Make a link” when that control exists, then leaves the link live. The file header in `web/apps/web/live/sweep.spec.ts:20-24` still says that the sweep revokes the link.

Consequence: A free sweep can create a public link to an existing deck without notice to its operator. The link stays live, and the delete flag only deletes a deck built by the sweep.

Correction: State that the sweep can create a link and leave it live. Correct the sweep header to describe the same behavior.

Regression check: Add a test or a review check for the free-run case with an unshared existing deck. Confirm that the instructions state the creation and persistence of the link.
