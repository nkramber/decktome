## Findings

### P1-1: A session can erase the spend file and restart the budget

Status: fixed in `68be1556e6331591f00699608ce767aa9943256e`.

Open at: `998057fbf07a498c4a43b828193229a856dcc28f`.

File: `go/internal/livespend/livespend.go:80-86`.

Trigger: a live-eval session deletes its writable bundle spend file after a paid run reaches the budget, then starts another paid command.

Expected: D-1169 requires a paid command to refuse a run after spend reaches the budget. D-1170 makes the session log the trusted source.

Actual: the earlier `Start` read only the bundle spend file. A missing file counted as zero spend.

Consequence: the session erased the only state that `Start` read, then started more paid commands.

Correction: `Start` now requires and reads the append-only ledger outside the run folder (D-1171).

Regression check: `TestStartReadsTheLedgerAfterTheBundleIsGone` passes. It refuses a spent ledger and allows a ledger below the cap.

### P1-2: A forged end line can let another paid command start

Status: open.

Open at: `1f62982301616070b2838c6aad1f4e50de101794`.

File: `go/internal/livespend/livespend.go:98-104`.

Trigger: a session kills a paid command after its start line, then appends a zero-cost end line with the same id.

Expected: D-1169 says a run with no measured end counts as the full budget, and no paid command starts after an unmeasured run. D-1171 says only a log can close a run that a log opened.

Actual: `Start` calls `SumFiles`, which reads the ledger without session logs. The forged end marks the run ended and measured, so `Start` sees zero spend and starts another paid command. The end-of-session sum catches this case, but only after that extra command runs.

Consequence: a killed paid run can bypass the inter-command budget guard and permit another paid run.

Correction: make `Start` treat a ledger run as unmeasured when its logged start has no logged measured end. Add a regression test that writes a logged start and a forged ledger end, then proves that `Start` refuses.

Regression check: no test covers this start-time path. `TestAFileEndDoesNotCloseARunThatALogOpened` proves only the final sum path.
