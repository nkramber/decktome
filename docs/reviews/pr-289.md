## Findings

### P1-1: The setup does not protect the copied credentials

Status: fixed in `9e1982441a50b10874fa1fe159a28fc090d37cad`.

Open at: `96cb6ae0301b07f656b5cf34a8a2499e90272988`.

File: `scripts/live-evals.sh:68-71` at the finding head.

Trigger: Create a credential file under umask `022`.

Expected: The setup creates private credential files. D-1141 and D-1164 require that another account can not read them.

Actual: At the finding head, shell redirection created mode `644`. The fix sets umask `077` and checks group and other permission bits.

Consequence: The old setup can expose the owner’s GitHub and Claude tokens to another local account.

Correction: The setup now uses umask `077`. The script and installer reject group and other permission bits and ACL entries.

Regression check: On this Mac, a mode `600` file passed. A mode `644` file failed. The later P1-2 check also rejects an ACL.

### P1-2: The credential check ignores read access control lists

Status: fixed in `63a3717083f84d3cc2895af1f11021c86558c4d1`.

Open at: `9e1982441a50b10874fa1fe159a28fc090d37cad`.

File: `scripts/live-evals.sh:262-268` and `scripts/live-evals-launchd.sh:62-68` at the fix head.

Trigger: Give a mode `600` credential file an ACL entry `everyone allow read`.

Expected: The script and installer reject a credential file that another account can read. D-1141 and D-1164.

Actual: The fix checks the ACL entries with `ls -lde` and refuses a file with any ACL entry.

Consequence: The earlier mode-only check can accept a file that another local account can read.

Correction: Both credential checks now reject ACL entries.

Regression check: On this Mac, the mode `600` file with `everyone allow read` failed the check. A clean mode `600` file passed. The mode `644` boundary also failed.
