Status: fixed in `c3f5878d91178298f6cec02c93a98fe3ebc281cd`.

Open at: `1ccaf429161ef45d8d895e43002b08c1e5db06e1`.

File: `go/internal/cards/newcards.go:125-132` at the original finding head.

Trigger: A pass for version v1 stops after a partial scan. A later snapshot writes a v2 marker, and its pass completes.

Expected: Process every pending marker. The PR-120 roadmap says a failed or stopped pass runs again, and one pass sends one push (D-1091).

Actual: At the original finding head, `LatestNewCards` returned only the newest marker. The worker then exited when that marker had a pass value.

Consequence: Decks that fit only v1 cards missed the panel and push.

Correction: `PendingNewCards` returns all pending markers oldest first. The worker joins their cards under the newest version. It preserves shown cards and cards newer than each deck's version. It records the pass end in each marker.
