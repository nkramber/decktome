## 3. Medium findings

### Rules engine (E)

- E-4 `derive.go:126-133`: commander eligibility uses the union of both faces. A non-legendary front face with a legendary back face (Bloodline Keeper) qualifies. CR 712.8a: only the front face counts.
- E-5 `derive.go:129`: legendary Vehicles and Spacecraft are commander-eligible since CR 903.3 (2026-08-07 text). The code accepts only Creature. Grist (planeswalker with a CDA) also fails.
- E-6 `checks.go:170-173`: Doctor's companion requires subtypes `Doctor` and `Time`. CR 702.124m: `Time Lord Doctor` with no other creature type.
- E-7 `checks.go:229-251`: the companion is not legality-checked, not color-identity-checked, and not counted for singleton. Lurrus as a companion in Modern with an empty sideboard passes.
- E-8 `rules_test.go`: the golden gate is 27 good and 31 bad decks, not 30 and 30. Confirmed with a subtest count.
- E-9 `rules_test.go:159`: the test "lutri in the 99 is legal" contains no Lutri.
- E-10 `checks.go:244`: `banned_as_companion` applies in every format. The Lutri ban is Commander-only.
- E-11 `checks.go:267-279`: ownership is counted per deck entry, not per Oracle id. Three in main plus one in side with three owned passes.
- E-12 `checks.go:272`: basic lands are exempt from ownership in owned-only mode. D-37 says "only cards in my library". Owner decision.
- E-13 `decksvc/service.go:52`: ownership is hard-wired to `ANY_CARD`. F-12 (printing exception) is not implemented. `ValidateResponse` carries no `legality_as_of`. No `decksvc` test exists.
- E-14 Untested paths. Partner with (positive and negative). Friends forever. Partner + Partner positive. Doctor pair reversed. Game Changer as commander. Restricted card split main and side. Unknown format. `FORMAT_ID_HOUSE`. Companion color identity. Bracket 6. Wastes.
- E-15 `formats.json`, `brackets.json`, `companion_bans.json`: `verified_at` is only in a comment. Nothing reads it.

### Cards and collections (C)

- C-5 `resolve.go:29-39`: a name-path match stores the input Scryfall id, so the entry claims a printing the index does not know.
- C-6 `collectionsvc/service.go:100`: a `FindByHash` error is swallowed and creates a duplicate document.
- C-7 `collections/parse.go:199-201`: `raw` is cut at byte 200. A cut inside a multi-byte rune makes the protobuf response invalid UTF-8. 15 fixture rows have non-ASCII names.
- C-8 `cards/parse.go:102`: an empty `oracle_id` (reversible cards) collides in the index.
- C-9 `collections/parse.go:114`, `resolve.go:35`: quantity overflows `int32` with no cap.
- C-10 `cmd/api/main.go:87`: no `connect.WithReadMaxBytes`. The 5 MiB check runs after the full body is in memory.
- C-11 `cmd/worker/main.go:49,61`: M-2 lag state lives in process memory. A restart or `-once` run loses the log line.
- C-12 `cards/refresh.go`: old snapshots are never pruned. About 108 MB per version.
- C-13 `scryfall/client.go:58,85`: a 429 is a generic error. Scryfall: "not acceptable to ignore 429".
- C-14 `scryfall/client.go:37`: a 5-minute client timeout caps a 77.5 MB download.
- C-15 `collections/parse.go:72`: a UTF-8 BOM is not stripped. `parse.go:35-51`: unknown finish or condition values default silently.
- C-16 `cards/index.go:43`: duplicate full names overwrite silently.
- C-17 `cmd/api/main.go:58`: `PROJECT_ID` defaults to `mtg-local`. Cloud Run does not set it. `main.go:53`: the first snapshot load runs before listen, which can exceed the Cloud Run startup probe.
- C-18 M-3 has no per-reason count. `imported_at` is stored but never returned. `language` and `set_name` are parsed but not stored.

### LLM layer (D)

- D-1 `llm/anthropic.go:66-70`: thinking tokens are dropped. The SDK has `Usage.OutputTokensDetails.ThinkingTokens`. The roadmap and handoff claim "Anthropic reports none". That claim is mine and it is wrong. Sonnet 5 thinks by default at effort `high`, so judge spend is under-counted.
- D-2 `llm/anthropic.go:67`, `config.go:154`: Anthropic cache-write tokens are billed at 1.25x input. The adapter prices them at 1x.
- D-3 `llm/config.go:96`, `env.go:48-73`: `LLM_REQUIRE_KEYS=1` does not stop `LLM_JUDGE_PROVIDER=fake`. Nothing in the repo sets the flag for production.
- D-4 `llm/roles.json:29-34`, `anthropic.go`: the judge runs with thinking on, cap 8192, attempt timeout 120 s. A truncation escalates to 65,536 tokens, which can outrun the timeout and burn the budget.
- D-5 `llm/client.go:25`: the doc says a zero `Budget` means the default. The code makes it fail at once.
- D-6 `llm/anthropic.go:74`: `model_context_window_exceeded` is classed as truncation. A higher cap can not fix it.
- D-7 Both adapters have zero unit tests. The reviewer gave an `httptest` plan.
- D-8 Sonnet 5 intro pricing ($2/$10 until 2026-08-31) is unverified. The table carries the list price.
