# Full audit, 2026-08-28

Note: the finding labels in this file (Q-, G-, C-, L-, T-, P-, W-) are audit-local. They are not the D-numbers of `docs/decisions.md`.

Scope: every file in the repo at `main` (`5a1fcfe`, PR #16 merged). Seven independent review passes ran in parallel. They covered the question workflow, the generator and rules, the card and collection layer, and the LLM and service layer. They also covered the command tools and the tuning loop, the contract and the build, and the docs. I verified every high finding first-hand against the code or the local snapshot before it entered this file. The date of each fact sits next to it.

Status legend: **H** ships wrong data, blocks a feature, or makes a measurement false. **M** is a real defect with a workaround. **L** is drift, debt, or polish.

## 1. Summary

- The tree is green. Build, vet, `-race` tests, golangci-lint, staticcheck, `buf lint`, `buf breaking`, web lint, typecheck, tests, and build all pass. Generated code matches the proto files byte for byte.
- The deployable API cannot build a deck (L-1, L-2). Only `chat-probe` wires a generator. Every deck gate ran on a path the API does not use.
- The question workflow loses state between turns in production (Q-1). The gate harness keeps the state in memory, so no gate run measured the production path.
- Six catalog rows ask a question and store the answer nowhere. Two more ask the user to choose between plans that are never named (Q-2, Q-3).
- The repair turn never sees the two findings that trigger it most (G-1). Two builder steps run after validation and leave the result stale (G-2, G-3).
- The card index lets 291 non-playable "front cards" win name lookups (C-1). "Savage Lands" and "Inferno" resolve to a card with no type and no legality.
- The tuning loop's budget guard does not stop the loop (T-1), the F-26 judge tool counts nothing (T-3), and the accept rule ratchets (T-6).
- Go 1.26.4 carries seven standard-library vulnerabilities that reach this code. 1.26.6 fixes them (P-1).
- The hand-off, `CLAUDE.md`, and the README send a new session to a merged branch and to answered questions (W-1 to W-4).
- `make test` costs 260 seconds because four tests load the 103 MB snapshot from a hard-coded path (C-8).
